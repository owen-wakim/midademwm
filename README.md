# Midade MWM — HTML/CSS/JavaScript starter

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — mobile menu, section navigation, footer year, and demo contact form

## Preview
Open `index.html` in a browser, or deploy the repository to Vercel as a static site.

## GitHub + Vercel
1. Add these files to the root of your GitHub repository.
2. In Vercel, import the repository.
3. Use the default static deployment settings; no build command is needed.
4. The output/root directory should be the repository root.

## Notes
- The meetings and gallery are placeholder content.
- The contact form opens an email draft and does not save messages to a database.
- No Supabase connection is configured yet.
- Never put a Supabase secret/service-role key in browser JavaScript.
